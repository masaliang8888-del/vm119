# 線上 VM 電腦預約與管理系統 (v2)

本系統包含完整的前端單一檔案網頁 (`index.html`) 與後台管理功能。

## 🌟 核心更新亮點
1. **管理員安全密碼**：更新為指定專屬密碼，後台介面與錯誤訊息完全去除密碼提示。
2. **真實 Email 寄信支援**：
   - **免伺服器直接發信**：整合了 **EmailJS SDK**，在純前端靜態環境（GitHub Pages / Netlify）也能真實寄送信件。
   - **一鍵開啟郵件用戶端 (Mailto 備援)**：若未串接金鑰，亦提供一鍵自動帶入連線帳密與收件同仁的寄信功能。
   - **連線資訊即時預覽**：預約完成後立即於畫面展示安全連線 IP、Port、帳號與密碼。
3. **資料持久化**：管理員設定的 VM IP、帳號、密碼自動儲存於瀏覽器 LocalStorage，重新整理不丟失。
