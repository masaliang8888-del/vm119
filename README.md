# 線上 VM 電腦預約與管理系統

本系統包含完整的前端單一檔案網頁 (`index.html`) 與後端 Node.js / Express 服務架構。

## 🌟 核心功能
1. **同仁線上預約**：支援 3 台 VM (VM-01, VM-02, VM-03) 即時時段選取。
2. **2 小時配額限制**：每位同仁以員編/帳號為基準，每日累計預約上限 2 小時。
3. **防衝突鎖定**：同一時段不可重複預約，亦不可跨台預約相同時段。
4. **管理員後台驗證**：支援 JWT 與管理員密碼驗證。
5. **帳號密碼維護與自動寄發**：後台可配置連線 IP、連接埠與專屬帳密，預約完成後模擬自動寄發連線通知信。

## 🚀 快速啟動方式
1. 直接在瀏覽器開啟 `index.html` 即可立即體驗完整互動介面（包含前台預約與後台設定）。
2. 後台預設管理員帳號：`admin`，預設密碼：`admin123`。
